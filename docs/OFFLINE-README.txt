TAGWERK INSTALLIEREN (einmalig, etwa 10 Minuten)

1. ZIP entpacken. Auf Android: in „Dateien“ (Files by Google) auf die ZIP tippen, dann „Entpacken“.
2. Auf github.com ein kostenloses Konto anlegen und anmelden.
3. Oben rechts auf „+“ > „New repository“. Name: tagwerk. „Public“ auswählen. „Create repository“.
4. Auf der leeren Seite den Link „uploading an existing file“ antippen.
   Alle 6 Dateien auswählen: index.html, manifest.webmanifest, sw.js,
   icon-192.png, icon-512.png, icon-maskable-512.png. Unten „Commit changes“.
5. „Settings“ > links „Pages“. Unter „Branch“: main und /(root) wählen, „Save“.
6. 1 bis 2 Minuten warten, Seite neu laden. Oben steht dann der Link,
   etwa https://DEIN-NAME.github.io/tagwerk/
7. Den Link auf dem Handy öffnen.
   Chrome: Menü ⋮ > „App installieren“.
   Firefox: Menü ⋮ > „Zum Startbildschirm hinzufügen“ bzw. „Installieren“.
8. Die App einmal mit Internet öffnen. Danach geht sie auch offline.

Fehlen auf dem Handy Knöpfe bei GitHub: im Browser-Menü ⋮ „Desktopwebsite“ anhaken.

UPDATE EINSPIELEN
Im Repository „Add file“ > „Upload files“, alle neuen Dateien auswählen, „Commit changes“.
Die alten werden ersetzt. Nach 1 bis 2 Minuten die App mit Internet öffnen.
Erscheint „Eine neue Version ist da“, auf „Neu laden“ tippen.
Der Fortschritt bleibt, solange der Link gleich bleibt.

NEUES SYMBOL
Android übernimmt ein neues Symbol nicht in eine schon installierte App.
Erst Backup exportieren, dann das alte Symbol vom Startbildschirm entfernen,
den Link im selben Browser öffnen und neu installieren.

WICHTIG
Dein Fortschritt liegt nur auf diesem Handy, im Speicher des Browsers.
Den Link nicht ändern. Ab und zu unter Einstellungen (Zahnrad) > „Backup exportieren“ sichern.
In Firefox „Browserdaten beim Beenden löschen“ ausgeschaltet lassen.
