TAGWERK INSTALLIEREN (einmalig, etwa 10 Minuten)

1. ZIP entpacken. Auf Android: in „Dateien“ (Files by Google) auf die ZIP tippen, dann „Entpacken“.
2. Auf github.com ein kostenloses Konto anlegen und anmelden.
3. Oben rechts auf „+“ > „New repository“. Name: tagwerk. „Public“ auswählen. „Create repository“.
4. Auf der leeren Seite den Link „uploading an existing file“ antippen.
   Alle 5 Dateien auswählen: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.
   Unten „Commit changes“.
5. „Settings“ > links „Pages“. Unter „Branch“: main und /(root) wählen, „Save“.
6. 1 bis 2 Minuten warten, Seite neu laden. Oben steht dann der Link,
   etwa https://DEIN-NAME.github.io/tagwerk/
7. Den Link in Chrome auf dem Handy öffnen, Menü ⋮ > „App installieren“.
8. Die App einmal mit Internet öffnen. Danach geht sie auch offline.

Fehlen auf dem Handy Knöpfe bei GitHub: in Chrome Menü ⋮ > „Desktopwebsite“ anhaken.

UPDATE EINSPIELEN
Im Repository „Add file“ > „Upload files“, die neuen Dateien auswählen, „Commit changes“.
Die alten werden ersetzt. Nach 1 bis 2 Minuten die App mit Internet öffnen.
Erscheint „Eine neue Version ist da“, auf „Neu laden“ tippen.

WICHTIG
Dein Fortschritt liegt nur in der installierten App auf diesem Handy.
Den Link nicht ändern. Ab und zu unter Einstellungen (Zahnrad) > „Backup exportieren“ sichern.
Wer das ganze Repository mit automatischer Veröffentlichung nutzen will: siehe docs/INSTALL.md im Repository.
